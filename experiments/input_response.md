# 입력 신호별 하강 뉴런 반응

연결된 가중치 모델에서 각 입력을 확인했다. 뉴런 그룹은 [neuron_groups.json](neuron_groups.json)에 정의되어 있다.

- 가중치: `0.02`; 반응 시간: `7 ms`; 입력 조합마다 네트워크 상태를 초기화했다.
- 단일 신호 검사는 입력 인코딩의 반응을 분리해서 보는 검사다. 실제 게임에서는 가까운 줄과 먼 줄에 각각 장애물이 있어 보통 3~4개 비트가 켜진다.
- 아래 발화 수는 `descending_CV` 1,303개 집단에서 센 값이다.

| 켠 신호 (단일 입력) | 입력 비트 | 발화 횟수 | 발화한 하강 뉴런 수 |
|---|---:|---:|---:|
| `near_left` | `100000` | 7 | 7 |
| `near_center` | `010000` | 0 | 0 |
| `near_right` | `001000` | 0 | 0 |
| `far_left` | `000100` | 0 | 0 |
| `far_center` | `000010` | 12 | 12 |
| `far_right` | `000001` | 0 | 0 |

## 실제 게임 입력 조합

가능한 36개 조합 중 **30개가 서로 다른 발화 벡터**를 만들었다. 발화 뉴런 수는 0~305개였고, 1개 조합에서 하강 뉴런 발화가 없었다. 입력 조합 사이의 평균 cosine 유사도는 0.526였다.
발화가 없던 비트 조합: `001100`.
같은 발화 벡터를 만든 조합: `001101`, `010100`, `011001`; `010010`, `010011`; `011010`, `011011`; `100010`, `101010`; `100011`, `101011`.

## 가중치 비교

가중치를 `0.025`로 바꾸고 단일 입력 6개를 다시 검사했다. 각 입력은 70~223개의 하강 뉴런을 켰고, 6개 반응 벡터는 모두 달랐다(평균 cosine 유사도 `0.616`). 그러나 이 설정으로 학습·평가 각 100게임을 돌렸을 때 평가 평균 보상은 `-1.94`였다. `0.02` 설정의 `-0.81`, 같은 평가 시드의 무작위 행동 `-2.11`보다 나았다거나 낫지 않다고 결론내리기엔 표본과 학습 방식에 한계가 있다. 현재 결과로는 반응량 증가가 게임 성능 향상으로 이어지지 않았다. 상세 결과는 [가중치 0.025 요약](../results/game-connectome-w025.summary.json)과 [턴 기록](../results/game-connectome-w025.csv)에 있다.

## 해석

단일 입력만 넣으면 6개 신호 중 2개에서만 하강 뉴런 발화가 관측됐다. 여러 신호를 동시에 넣으면 입력 조합에 따라 반응 벡터는 대체로 달라졌지만, 일부 조합은 발화가 없거나 같은 벡터를 만들었다. 따라서 연결은 신호를 전달하지만, 현재 가중치·시간창·뉴런 선택으로는 6개 입력을 각각 안정적으로 구별한다고 보기 어렵다. 가중치와 반응 시간에 따라 결과가 바뀔 수 있으며, 이 검사는 생물학적 시간척도나 실제 시야 대응을 검증한 것은 아니다.

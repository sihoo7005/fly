# FAFB v783 consolidated cell types

This table maps FlyWire root IDs to the primary cell type and any additional cell type annotations.

- Source: FlyWire Codex, **Cell Types** data product for FAFB v783
- Retrieved: 2026-10-26
- Rows: 138,327 neuron records (plus the header)
- Columns: `root_id`, `primary_type`, `additional_type(s)`
- License: CC BY-NC 4.0 (Attribution-NonCommercial 4.0 International)
- Citation guidance: https://flywire.ai/guidelines

The CSV is the decompressed content of Codex's `consolidated_cell_types.csv.gz` download. Codex notes that its downloadable files are synchronized with its current database and may differ from the original October 2024 publication-time snapshot.
